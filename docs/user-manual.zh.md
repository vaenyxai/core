# Vaenyx 使用手册

Vaenyx 能做的每一件事,按你会用到的顺序排。一条一件事:是什么、在哪点、点完会怎样。

在 app 里看这份手册:**设置 → Manual**。

---

## 先知道三件事

- Vaenyx 跑在**你自己那台电脑**上。那台电脑关机或睡着,什么都用不了 —— 手机不行、
  浏览器不行、定时任务也不会跑。
- 你的数据都在那台电脑上,放在 `userdata/` 里。Vaenyx 自己不会把它传到任何地方。
- 回答你的那个模型**不在**你电脑上(除非你选了本地模型)。你打的字会发给你连接的那个
  模型后端。

---

## 0. 安装时会问你什么

- **选择要下载的组件** —— 选安装位置那一屏上面有五个勾,一项一句话,下载什么由你
  决定:你的 ChatGPT 订阅、你的 Claude 订阅、手机访问(装 Tailscale),以及中文和
  英文的离线语音。**一个都不勾也能装完、也能正常用。**
- **默认只勾了 Tailscale** —— 它最小,而且「在手机上用」本来就是 Vaenyx 的用途之一。
  两个订阅默认不勾:各约 250 MB,只有已经在付那个服务的人用得上;不勾也没关系,
  第一次连接时 Vaenyx 会自动下对应的那个。
- **大小写在这里,不写在那一屏上。** 给你个底:Tailscale 约 37 MB,两个订阅通道各约
  250–300 MB,语音每种 60 MB、共用一个 21 MB 引擎 —— 加第二种语言只多 60 MB,不是
  81 MB。这些都不含你已经下好的安装包;页面最底下那行「还需多少磁盘空间」照旧按
  真实数字检查。
- **这次跳过的,以后在设置里一键补装** —— 同样的按钮、同样的下载,不用重装。
- **大件是装完之后下的,不是装机过程中下的** —— 订阅通道和语音在 Vaenyx 第一次启动时
  下载,逐个显示进度。这是有意的:某个组件下不下来时,它可以明说,而不会把整个安装拖垮。
  **Tailscale 是例外**:它在装机过程中就装好,这样紧接着的手机一步能直接开始连接。
- **勾了手机访问 = 装上 Tailscale,不等于已经连通。** 首跑流程会带你用自己的
  免费 Tailscale 账号登录,并显示手机用的二维码。
- **首跑是一条顺序走完的短路** —— 建账号(本机密码,至少 6 位;那一页没有别的)→
  连模型(ChatGPT 或 Claude 订阅,或下拉里选一家粘 API key)→ 设手机:没装就装、
  登录、扫码。每个新账号都走这几步 —— 必要的东西不用你之后去设置里找。
- **硬盘空间不够**会在开始前就告诉你,写明是哪个盘、还差多少。两个盘不同时会各查一次:
  Vaenyx 装在哪个盘,以及下载解包要用的 Windows 系统盘。

## 0b. Vaenyx 记住了你什么

- **设置 → Vaenyx Me → Vaenyx 知道的事** 就是全部清单。一条一行,每行都写明**是怎么知道的**:
  来自某次对话、你自己加的、还是你从某个网页拿来的(会写明网址)。
- **变了不会删掉旧的。** 搬了家,旧地址不是被抹掉,而是**被标上截止日期**。所以「我三月住哪」
  仍然答得出来;每行的 **历史** 按钮就是看它取代了什么。
- **「忘掉」是标日期,不是删记录** —— 一条记忆不会悄无声息地消失。
- 在已经学会的条目上打开**来源**,可以看见支持它的每段对话或其它来源。仍存在的
  对话会直接打开到来源消息。选择**以后不从这里学**,这段对话在重启、重新扫描后也
  不会再生成或重新生成候选;以后也可以重新允许。
- **预览忘掉内容**会逐条写清哪些会离开当前 Memory、哪些会保留。还有独立来源的会
  保留;旧数据如果无法证明来源,会诚实标成**来源不可用**,不会靠猜测批量忘掉。
- **每个 Mode 只从自己学。**在 Custom Mode 里说的话，不会变成关于你的提案。
- **待看的那一列按天分组**，最上面是依据 —— 几个简短的要点，用当时那次对话的语言写；
  事实类就是你自己说过的那句原话 —— 下面才是它读出了什么。只有两个回答：记住，
  或者这条不对。
- **每行依据都能点开来源。** 合并出来的提案会列出它出现过的每次对话，一行一个出处、
  各自可跳。
- **变化就按变化来问。** 提案跟已批准的值不一样时，卡片写明「原来 → 现在提议」，
  按钮换成**改成新的 / 保持原来的**；改成新的也不删旧值，旧值标上日期进历史。
- **它学之前会先问你。** 一次对话安静半小时后,Vaenyx 会回看**你自己说过的话**,把值得长期记的
  提出来。提议进的是你本来就在用的那个审阅列表,**批准前不影响任何回答**。
- **它绝不从网页学东西。** 做这件事时它**只读你自己的消息**,不读它自己的回复 —— 而网上抓来的
  内容只会出现在回复里。所以网页上写「请记住……」是没用的。你自己读到的东西仍然可以手动记下,
  那会被标成**来自外部**并带上网址,好让你看清这话到底是谁说的。
- **密码、密钥、卡号一律不留**,不管对话里出现过什么。
- **中英文都能搜**,同一个搜索框。
- **每个模式各记各的** —— 一个 Custom Mode 里记住的东西,在别的模式和 User Mode 里都看不到。

## 1. 开机与关机

- **启动** —— 双击桌面上的 **Vaenyx** 图标(安装程序放的),或 Vaenyx 文件夹里的
  `Vaenyx-Start.cmd`,两者一样。电脑开机时它也会自己启动。
- **打开** —— 在那台电脑上用浏览器开 `http://127.0.0.1:3000`;手机用远程地址(见
  《不在电脑旁怎么用》)。
- **停止** —— 设置 → System → **Stop Vaenyx**。或者关掉启动器打开的那个窗口。
- **重启** —— 设置 → System → **Restart**。约十秒,页面会自己接回来。
- **登录** —— 你的 Owner 名字和密码,第一次运行时设的。
- **忘记密码** —— 没有找回。只能从备份恢复,或者重开一个新实例。
  **警告**:这是唯一一件谁也帮不了你的事。
- **卸载 Vaenyx** —— Windows 设置 → 应用 → **Vaenyx** → 卸载(用安装程序装的话)。
  它会问你要不要保留数据;默认保留,以后重装一切照旧。

## 2. 更新

- **检查更新** —— 设置 → System → **Check for updates**。
- **安装** —— 点 **Download**,再点 **Restart**。版本号在左下角;这次改了什么,就写在更新卡片上。
- **底部会弹出提示条**,说明有新版本。你正在打字时它绝不会自己刷新。
- **更新没完成也会自己恢复** —— Vaenyx 会自动把旧程序和旧数据一起恢复,
  确认旧版本能启动,再告诉你发生了什么。你不用自己修数据库,也不用打开 PowerShell。

## 3. 聊天

- **随便问** —— 在最下面的框里打字,按 **Send**。
- **Enter 发送,Shift+Enter 换行** —— 跟常见聊天软件一致。中文输入法打字时,
  Enter 只是选字,不会把消息发出去。手机上就用 Send 按钮。
- **没写完的消息刷新后还在** —— 文字和选好的照片或文件只保存在当前浏览器，最多
  十四天。只有回到同一个账户、Mode 和对话（或任务）时才会恢复，并明确显示
  **已恢复草稿**；Vaenyx 绝不会自己发出去。按**丢弃**可删除这一份。选中的附件要到
  你按下 **Send** 才会上传。退出登录，或删除它所属的 Mode / 对话，也会删除对应的
  本机草稿。设备空间不足时仍会保住文字，提示里会写清哪些附件没能恢复。
- **需要你决定时一按就答** —— Vaenyx 真需要你选一项时,回复里会出现两个或更多大按钮。
  你可以点一个、自己输入答案,或按**跳过**。第一次回答会成为记录,刷新页面或换设备也一样;
  连按两次不会重复提交。跳过会一直清楚写着“已跳过”,绝不会被当成同意。原本需要确认的
  动作仍然要另外确认。
- **用说的** —— 麦克风按钮。需要「听」这一行开着并且设好引擎
  (设置 → AI Settings → Capabilities)。
- **听回答** —— 每条回复右下角的 ▶ 按钮。它念的是**总结**,不会把标点念出来。
  只有你是用说的,它才会主动用说的回你。如果你把「念」这一行关掉了
  (AI Settings → Capabilities),这个按钮直接不出现;你自己录的语音消息照样能回放,
  因为那是你的声音,不是 Vaenyx 在说话。
- **发照片** —— 相机按钮(现拍)或图片按钮(选一张),任何时候都在。模型自己看
  照片,你不用描述它 —— 一张照片不配一个字,也是一条完整的消息。
- **在照片上标东西** —— 用你自己的话让它标出来就行。红点和名字会出现在**你发的
  那张照片上** —— 回复不会把图再贴一遍。照片上的图层按钮可以开关这些标注。
- **看清楚一点** —— 点照片全屏,两指放大。标注和图层按钮会跟着一起放大。
- **发文件** —— 文件按钮。收 PDF、纯文本文件(.txt、.md)和 Word / Excel /
  PowerPoint 文件(.docx、.xlsx、.pptx):一个按钮,怎么读由 Vaenyx 自己分流。
  Office 文件读出来的是里面的**文字** —— 排版、图片和图表不会被读到,所以如果
  文件的重点在图上,请另存为 PDF,PDF 是按图来读的。老格式(.doc、.xls、.ppt)
  读不了 —— 另存为 PDF 或新格式再发。
  - 超过十页会**先问你**,并告诉你有多少页 —— 长文档在付费模型上是真金白银。
  - **超长的文字永远不会被悄悄截断。** 一份文档的字多到没法整份交给模型时,
    Vaenyx 会把全文存在你的电脑上,交给模型的是开头、结尾,外加一句老实话:
    中间省略的是第几页到第几页。会用工具的模型(Claude 订阅)自己去取需要的
    页;其它模型下,你说一声页码 ——「看第 5–8 页」—— 那几页就随你的下一条
    消息送到。
  - **删对话就删文件。** 发进对话的文档,在对话删除时一并从这台电脑上删掉
    (别的对话还在用的会保留);没有任何对话引用的残留文件,一天内由后台
    自动清理。
  - 如果「读文档」这一行是关的(AI Settings → Capabilities),文件在门口就被挡下,
    Vaenyx 会说清楚是谁挡的:是这一行的开关,还是你当前所在的模式 —— 后者不是开关,
    在模式里面也改不了。
- **打断回答** —— 回答过程中按 **Stop**,立刻停。
- **换模型 / 换思考强度** —— 输入框下面那两个选择器。只影响当前这个对话。
- **给对话起名并写用途** —— 打开对话顶部的 ⋮ 菜单 → **编辑资料**。标题必填；
  可选的一句话用途方便辨认和搜索。用途只用于整理，绝不会暗中变成给模型的指令。
  清空用途栏即可删除它。
- **归档或删除对话** —— 对话顶部的 ⋮ 菜单。
- **归档会让对话安静下来,不会把它抹掉。**历史、Project、Routine 和记忆范围都会保留。
  如果它有正在运行的定时,确认框会明说;归档会立刻暂停之后的运行,但保留周期、时间和
  时区。取回对话后,定时仍保持暂停;想重新运行时,在任务或 **Scheduled** 页面按一次
  **恢复定时**。
- **永久删除只能从“已归档”开始。**删除前必须明确选择**只删除对话**(保留已批准的
  Memory),或**删除对话并忘掉可识别的 Memory**;两个选项都不会预先替你选。预览会列出
  会忘掉的内容,也会说明因为还有独立来源或旧来源不明而保留的内容。所选的对话与
  Memory 改动会一起成功或一起失败。共用 Routine、手动 Project Memory、Project 指令和
  Owner 连接都不会被这个选择删除。
- **搜以前的对话** —— 点 **New** 下面的**搜索对话**（或按 `Ctrl/Cmd + K`），输入
  关键词；要找完整短语，就用英文双引号括起来。搜索会检查标题、用途和消息。结果包括
  进行中、置顶、主对话和已归档对话；点一下直接打开命中位置。搜索只在这台电脑上进行，不会调用模型或云端服务。
  User Mode 能搜它监督的所有 Mode；Custom Mode 只能搜自己。打开已归档结果不会把它取回。
- **未读** —— 对话左边那颗彩色圆点会呼吸,表示里面有新东西。**读过就是各处
  都读过**:手机上打开了,电脑上的红点也会灭(电脑一分钟内知道,或你一回到
  这个页面就立刻知道)。
- **点进对话停在哪** —— 所有对话都停在最底下、最新的那条。唯一的例外是未读的:
  它停在你还没看过的第一条,从那里往下读。
- **它记得多少** —— 最近三十来条完整记得(一问一答永不拆开),更早的压成一份
  固定结构的滚动检查点,再加上你批准过的《Vaenyx Me》条目。
- **查资料** —— 它到底会不会真的去查,取决于你用的是哪个主模型。今天只有 ChatGPT
  (Codex CLI)和 Claude 这两个订阅会真的联网搜;别的模型都是凭训练时记住的东西回答,
  过时了也一样说得斩钉截铁。「上网」这一行(AI Settings → Capabilities)出厂是**开的**,
  而且把它关掉并不能拦住那两个订阅在普通对话里搜 —— 关掉挡的是 Method 和 app 钥匙。
  这两件事卡片上都写着,下面《AI 设置》一节讲得最全。
- **你电脑上的文件** —— 除非你把「取文件」这一行打开,**并且**亲手点名它可以看哪几个
  文件夹(AI Settings → Capabilities → 取文件),否则 Vaenyx 读不到这台电脑上的任何
  东西。两件事缺一不可:只开开关、一个文件夹都没点名,它照样一个字都读不到。点名之后,
  也只有那几个文件夹里的东西打得开,而且只限文字文件 —— 这台机器上的其他东西不会交给
  任何模型。出厂时这一行是关的,名单是空的。

## 4. 项目

- **Project 是可选的整理方式** —— 不建、不选也可以直接聊天。普通新对话一律先进入
  **Unsorted**；那里没有共用的 Project Memory 或指令。
- **Project 是什么** —— 多段相关对话共用 Context、Memory、常驻指令和文件的边界，
  不是另一种工作项目。
- **管理 Project** —— 设置 → **整理**。新建、改名、指令和 Memory 都在这里；
  没有你的明确确认，Vaenyx 绝不会新建或改名。
- **整理已有对话** —— 对话里的 ⋮ 菜单 → **Move to group**。
- **Inbox 另算** —— **New** 下面那条受保护的主动对话不是 Unsorted，也不会放进 Project。

## 4a. Vaenyx 主动找你的那条对话

- **在左边最上面、New 的下面**，带一个月亮。它永远在那儿，删不掉、归档不了、也多不出第二条。
- **每个 Mode 一条。**Custom Mode 有自己的，两边不互通。
- **有东西等你时才会出现一个数字。**点开对话不会把它消掉 —— 看过不等于处理过。
- **点那个数字**，就在对话旁边逐条回答，不用离开。对话停在原地不动。
- **它就是一条真对话。**像平常一样打字就行。
- **说「去改某个设置」或「打开某个页面」**（比如改 Agent 名字、开手机访问），
  回复下面会出一个「跳过去」按钮。按一下就到那个页面；它绝不会替你改任何设置，
  不理它也没任何代价。
- **在任何对话里说「用某个 Routine 做…」**，要求会自动送到那个 Routine
  自己的对话里跑，你也一起跳过去。原来那条对话会留一行回执，写清发去了哪里。

## 5. Vaenyx Me

- **每个 app 一折** —— 开关、地址、上限、用量一直看得见;每个 app 的钥匙、登录和测试结果
  点它的名字展开。
- **是什么** —— Vaenyx 注意到的、关于你的事实,之后每个对话都会用上。
- **在哪** —— **Vaenyx Me** 页面。
- **没批准的一律不用。** 每条候选都有 Approve / Reject。
- **以后想删** —— 同一个页面,删掉即可。
- **自己加一条** —— 那个页面上的手动表单。

## 6. Method 与 Routine

- **Method** —— Vaenyx 会做的一件小事,用大白话的步骤写成。
- **Routine** —— 你真正在用的成品（界面上只写 Routine），由一个或多个 Method 组成。它看起来像一个对话,
  用着用着会长出额外的按钮(Journal、Gallery)。喂了照片的那次运行,结果会
  把那张(带标注的)照片放在最上面,文字跟在后面。
- **给结果配一张图** —— Routine 还能把"做出来是什么样"画出来:做好的菜、
  收拾好的房间。在 Library 打开它、点 **Edit**,在 **结果配图** 里写清楚要
  画什么(或者直接在它的对话里说)。之后每次结果最上面都会是一张新生成的
  图。需要连接画图模型;没连就跟以前一样只出文字,绝不会为了配图卡住。
- **现成的家庭结果** —— Vaenyx 自带 **Receipt Record（收据记录）**、
  **Warranty & Manual Record（保修与说明书记录）** 和 **Material Takeoff
  Check（工程量复核）**。重要数值旁会写依据和确定性。收据记录只用于整理,
  不是税务或会计建议;保修记录不替你判断法律权利;工程量只是初稿,订料或施工前
  必须由胜任的人复核。
- **改正或再跑一次** —— 当前版本新生成的结果上,点 **纠正并重跑** 会重新打开
  当次确认过的字段;点 **重跑** 会原样重复输入。纠正会新增一组 Journal / Gallery
  记录,旧记录不变;它只教这个 Routine 的本地输入解析,不会改写 Method。
- **怎么做一个** —— 在对话里把步骤说出来。一步就是一个 Method,多步就是一个 Routine。
  Vaenyx 会起草,并在保存前给你试跑一次。
- **怎么改进一个** —— 直接说就行。在这个 Routine 自己的对话里说要改什么
  ("以后给我三个选择"),Vaenyx 会分清这是"改它"还是"喂给它的内容" ——
  真分不清时会弹一个大大的二选一,绝不瞎猜。也可以在主对话里说
  ("让晚餐规划列出缺的食材"),Vaenyx 会跳到那个 Routine 的对话去。
  两条路都落在同一张提案卡上:一句话说明 + 改动对比,可以**先试跑一次**
  (真的跑,但什么都不写),你点确认才保存。改 Method 用的也是这张卡。
  Library 里的 **Edit** 页留给想动手细调的时候。不管从哪里改,它都还是
  同一个 Routine:同一个对话、同一份历史,旧结果保持当时的样式。版本号由
  Vaenyx 自己递增。如果行为变了,授权给这个 Routine 的 app key 会停用,
  要你在 Token 页里重新授权 —— 绝不悄悄进行。社区 Routine 不能原地修改。
  另外,在对话里建好一个新 Routine 后,那个对话就直接是它的第一个对话,
  接着在里面喂内容用它就行。
- **放在哪** —— **Library** 页面，四个页签：Routine / Token / Method / Community。
  每个页签第一行写自己是干什么的，列表上方都是同两个按钮：新建，或从社区找。
  Method 页多一个：导入 SKILL.md。
- **Community** 页签里是你的社区账号。只有发布才需要它 —— 用别人发布的东西不需要账号。
- **发布** —— 按钮在弹窗标题行上，× 的旁边。
- **卡片只写名字** —— 点开才弹出全部内容（描述、步骤、标签、版本、发布）。
  只有需要你动手的东西会留在卡片外面：有新版、几条待看、几个例子答案变了。
  弹窗用右上角 × 关，手机上按返回也行。
- **改配方** —— Library → 那个 Method → **Edit recipe**。
- **等你看的修正** —— app 把改过的答案传回来后，会先在那个 Method 里等你看。
  **Method** 页签上会标出总数，卡片上写各自有几条。点「留下」就变成一个例子，
  并且从列表里永久去掉。
- **更新完社区 Method，可以拿你自己的例子验一道。**更新一完，
  弹窗就会问你。它会拿你积累的例子（最多 6 个）重跑一遍，把答案对一对 ——
  作者替你查不了这个，他测的是他自己的例子。只要有答案变了，卡片上会出一个
  红标记，上一个版本就在旁边一个按钮。每个例子都是一次真实的模型调用，
  所以只有你点了才跑。
- **改社区来的 Method，会变成你自己的一份副本。**对方那一份不会被改：
  它还在，也还会继续收到作者的更新。你的副本名字由你起，会永久标注原作者，
  并且从此它的修正只留在这台电脑，不再回传给作者 —— 那些修正讲的是你的步骤，
  不是他的。
- **试跑** —— 同一个页面。是真跑,但不改任何东西。如果这个 Method 伸手要了它没拿到的
  能力,结果框会在输出上面写清楚,并说是三层里的哪一层拦的。
- **标签** —— 在 Library 页面改名和归类。
- **导入 / 导出** —— Library → **Import Skill** 可以吃一个 SKILL.md 文件夹;
  每个 Method 也能同样导出。
- **让别的 app 用** —— Library → **Token**。Token 就是一把 app 钥匙:你自己另一个
  app 拿着它,就能调用你授权给它的那个 Routine 或那几个 Method,别的都调不了。
- **这把钥匙能做什么** —— 钥匙卡片上的 **它能做什么**。和 AI 设置里同样的八项能力、
  同样的顺序,每项一个勾。新钥匙一开始**什么都没勾** —— 只能跑你授权的那份配方,
  再多一点都没有 —— 卡片上直接写着它能做什么,不用点开。
  - **「取文件」永远给不了钥匙。** 那一行会明写这句话,而不是干脆不显示。替别的程序
    伸手进你自己机器里的文件,不是一把钥匙该带的东西,它要也没用。
  - **「上网」要单独批准一次** —— 单独按一下,不跟其他几项一个勾。因为一把能上网的
    钥匙,可以把这台机器变成别人上网的通道。要收回,拨掉那个开关就行。
  - **天花板照样管用。** 在 AI 设置里关掉的能力,这里显示**整台机器都关着**,根本勾不上;
    关掉之前已经给出去的那一项会留在钥匙上,机器说不行的期间它什么也做不了,
    等你把机器上的开关打开,它立刻又能用。
  - **只能在 User Mode 里改**,和另外两层一样。
  - **app 会被告知什么** —— 如果 Method 要的东西这把钥匙没有,这一次照跑,只是不带那一项,
    并且答案里会写明是哪一项、被三层里的哪一层拦下的。绝不会一声不吭地跳过 ——
    不然「被拒绝」和「答得不好」就分不出来了。
- **你之前建的钥匙** —— 这个功能出现之前建的钥匙,全都是一项没勾,谁也没有凭空多出本事。
  按每个 app 真正需要的,自己勾。

## 7. 社区

- **看别人做的** —— **Community** 页面。
- **安装** —— 点 **Install**,先看安装说明,再确认。说明会写明这是 Method 还是 Routine、
  名称、作者、来源,以及将要安装的准确版本。要是安装包在你看完之后变了,Vaenyx 会停下,
  让你重新打开说明,不会暗中换成另一个版本。
- **安装或更新前先看能力。** 同一份说明会列出这个项目请求的每项能力。**可用**表示
  这版 Vaenyx 能提供,**设置中已关闭**表示是你关掉的,**不支持**表示当前版本还做不到。
  更新时会标出这次新请求的能力。安装不会替你打开能力、放宽当前 Mode,也不会补上缺少的
  模型连接。
- **Community 项目不能自带可执行 Tool 或代码。** 它们只是声明式配方和编排,只能请求
  Vaenyx 内置或审核过的 Tool,而且仍受现有全局设置、Mode 和运行时限制。
  **未请求任何能力（No Capabilities requested）**只是在说这张能力清单;你交给配方的
  普通文字或其他输入,运行时照样会用到。
- **发布自己的** —— 你自己条目上的 Publish 按钮。需要 Google 或 GitHub 登录,
  因为上面要署你的名。
- **如果它需要 Vaenyx 还做不到的东西** —— 发布会被拒绝,这个 Method 留在这里,
  照常给你用。在这台电脑上跑不起来的 Method,在别人的电脑上一样跑不起来。
  然后 Vaenyx 会**问你**:能不能把「有人要过这一项」记下来。记下的只有那项能力的
  名字和一个次数 —— 不包括这个 Method 的任何内容、不包括它的配方、也不包括这台
  电脑上的任何别的东西 —— 而且只留在本机;等哪次更新真的把它做出来了,Vaenyx
  知道它一直在等,会告诉你一声。你说不,就什么都不记,别的也一切照旧。
- **暂停发布** —— 设置 → Sharing。暂停期间你的东西一律不出去。
- **你做的纠正可以变成共享示例** —— 一定先去掉个人信息,而且事后可以撤回
  (设置 → Sharing → 飞轮列表)。
- **看看会发出去什么** —— 在任何一条等待中的条目上点「看看会发出去什么」。
  那就是真正会出去的内容本身,不是概述,同时会列出遮掉了哪些东西。
  自动去标并不完美 —— 这正是 48 小时等待存在的原因,也是这一眼值得看的原因。
- **涉及健康、家人、金钱的,绝不会自己发出去。**它会被扣下来给你看,
  看完之后,由你逐条放行。没有任何设置能提前替你回答这个问题 —— 这是故意的,
  每一条都是一个单独的决定。放行也不会提前发送:它照样等满窗口,你随时可以拉回来。

## 8. 任务与定时

- **一次性任务** —— 让它做一件事,Vaenyx 会归档成一个任务。
- **定时任务** —— **Scheduled** 页面。可设每天、每周或按模式运行。
- **暂停的定时仍会显示。**原来的时间设置都在,旁边只有一个明确的**恢复定时**按钮;
  取回已归档的对话不会替你按下它。
- **看跑过什么** —— 同一个页面:每次运行、结果、用了多久。
- **取消或重试** —— 运行记录上的按钮。
- **长任务不用一直开着画面盯** —— 任务对话里只有一张进度卡,会显示等待开始、进行中、
  等你回复、已完成、失败、已取消或已中断,以及当前步骤和做完的步骤。刷新、重启,或换到
  另一台已登录设备,还是同一张卡;迟到的旧更新也不会把进度倒退。失败或中断时可直接
  **重试**,完成后可跳到已经保存的结果。卡片只放简短状态,绝不放模型的私下推理或原始日志。
- **跟任务对话** —— 任务底部那个输入框,和聊天那个一样能发**照片、PDF、语音**。
  它底下本来就是同一个对话,所以**每一个任务都自动有**,不管是多久以前建的。
- **重复的任务不会重复内容。** 每次运行都会被告知**前五次已经给过你什么**,并且只有
  一条命令:不许再给一遍。那里面的事如果有了实质变化,就先讲**变了什么**;没变就去找
  前几次没碰过的地方 —— 别的来源、别的角度。真的没新东西时,它会用一句话说清楚,
  而不是拿你已经读过的内容凑数。你在任务对话里提过的要求(格式、长度、不要什么)
  照样每次都算数 —— 要新的只是**内容**。
- **前提** —— 到点时电脑必须醒着。如果睡着了,那次运行会标为失败并写明原因;
  绝不会悄悄换个模型重跑。

## 9. AI 设置 —— 能力与模型

- **在哪** —— 设置 → **AI Settings**。两张卡,分工永远不变:**Capabilities** 管
  「准不准做、由哪个模型做、测一次看它真的行不行」,**Models** 管「把模型连上」。
  各家服务商的 **API key** 都在 Models 里贴,没有例外。(app 的**模型钥匙**是另一种
  东西:那是敲订阅通道用的,在那张卡片上生成、也在那里换掉 —— 见下面《订阅通道》。)
- **Models 只管连账号,型号在 Capabilities 里选** —— Models 那张卡只问 key,
  不问型号。哪个模型干哪件活,在每一行能力上单独问一次,因为答案本来就不一样:
  你想拿来聊天的模型,通常不是你想拿来看照片的那个;共用一个答案,就是「为了聊天
  挑了个好模型,结果每张照片都挤在它最紧的免费额度上」的由来。
- **每件活都有主用和备用** —— 展开一行能力,会看到两条。先选账号,再从这个账号
  的**使用中**型号里选 —— 就是你在下面 Models 里搜到、测过、按了「使用」的那些。
  **备用**那条一开始是空的,要你自己填 —— Vaenyx 永远不会替你选。
- **只有主用「完全答不上来」时才会换备用** —— 免费额度用完、钥匙被拒、型号下架、
  对方服务挂了、连不上。答得不好不算,那种时候换人只会把问题盖住。真的换了,
  回复结尾会有一句大白话:换了谁、主用是怎么了、错误代码是多少 —— 绝不偷偷换掉
  让你事后纳闷「这次回答怎么不一样」。
- **主模型是一个预选** —— 在 Capabilities 最上面。其他每一行都可以选**跟随主模型**,
  不用自己指定账号:它就用主模型的账号和型号,主模型的备用也一起跟,所以主模型一换,
  跟随的行全部一起换。**文字**(对话、Routine、Method、日记)是它正下方普通的一行,
  带自己的测试按钮,默认跟随主模型,想换再单独指定。聊天框下面的切换只换那一个对话,不会改这些行。
- **免费还是付费,按「哪件事」标** —— 每家都有标记,而且**同一家在不同能力上可能不一样**。
  最该知道的是 Gemini:它的免费档覆盖文字、看图、听、PDF 和念,**唯独生图一分钱额度都没有** ——
  所以它在「画」那一行会写明要付费。
- **这一行关掉会影响谁** —— 能力行上会写有多少个 Method 在用这一项(如「3 个 Method 在用」),
  让你在关之前就看得见后果。
- **能「念」的有两家,外加本机那个** —— Gemini(中英文都行)和 Cloudflare Workers AI
  (**只会英文** —— 遇到中文它会明说,不会瞎念)。装在本机的语音中英文都念,
  不花每次的钱,也什么都不出这台电脑。
  - **Gemini 免费档是每分钟三次**(2026-08-07 实测 API 得出)。第四次会被挡几秒,
    Vaenyx 会直接告诉你还要等几秒,而不是含糊地说「额度用完了」。本机语音没有任何限制。
- **免费额度** —— 标题旁边的 **免费额度** 按钮打开上一次查到的答案;挨着它的
  **再问一次** 会重新问一遍主模型,问完直接把新答案给你看。
  **注意**:结果旁边会写明**是哪个模型答的、哪天答的** —— 免费额度天天变,而模型会非常
  自信地答错。用之前请到服务商官网确认。
- **分成两段,绝不混**
  - _用你已有的订阅_ —— ChatGPT(Codex CLI)和 Claude。它们固定排在 Models 卡最
    上面,OpenAI 第一、Anthropic 第二,连没连都在,登录按钮就在卡片上;在 app 里
    点一次登录即可。这**不是**免费额度,是你自己花钱买的订阅。这两个都需要一个**安装包里没有**的
    组件,所以第一次点登录按钮时会先下载:ChatGPT 大约一分钟,Claude 约 250 MB。
    安装程序里也有这两项的勾选,勾了就在装机时下好,省得第一次用时等;不勾也一样,
    不用订阅的人两个都不下。下载失败会明说,下次点会重来;
    Vaenyx 其余功能不受影响。
  - _免费 API 额度_ —— 选一家,粘贴它的 key。
- **Capabilities 那张表就是全部** —— 一种能力一行,一行里两件事都在:这件事由**哪个模型**
  做,以及**准不准**做。听、念、看、画各自选模型;读文档、取文件和上网跟主模型走,
  行上会写明。
  - **听** _(声音进)_ —— 语音转文字。
  - **念** _(声音出)_ —— 文字转语音。
  - **看** _(图形进)_ —— 看照片。
  - **画** _(图形出)_ —— 生成图片。
  - **读文档** _(多页文档、PDF)_ —— 你传上来的文件。
  - **图转文** _(图里的字)_ —— 把扫描件、照片上的字变成文字,用**专用 OCR 引擎**
    (Mistral OCR),故意不用主模型 —— 聊天模型看不清一个字会编一个「看着合理」的,
    报价单上的数字是要进钱的。读扫描 PDF = 图转文 + 读文档两个开关搭着用,所以它们
    是分开的:只开图转文,扫描件在本机变成文字给你自己看,不送任何模型。关着图转文
    时丢进扫描件,会得到一句明白话和一个「打开图转文」按钮,不会静默返回空。照片同理:
    开着图转文时,你发的照片里的字会由同一个引擎精确读出、连同图片一起交给模型 ——
    同一张纸,拍照和扫描读出来一个样;每张照片计一次小额引擎费用。
  - **取文件** _(本机文件)_ —— 打开你亲手点名的那几个文件夹里的文字文件,名单就在这一行
    自己的设置里。只限文字文件,而且不能太大。开文件的是 Vaenyx 自己,不是模型 ——
    模型拿到的只是文字,它没有任何能碰到硬盘的工具,所以主模型是哪个都行。PDF 仍然走聊天里的文件按钮,
    那是「读文档」。Method 和 Routine 目前还用不了这一项。
  - **上网** _(网页)_ —— 出去查网页。
- **开关就是天花板** —— 在某一行关掉的东西,任何 Method、任何模式、任何 app 钥匙都够不着,
  不管它们要什么。只有「上网」还差一步:关掉它,Method 和 app 钥匙就不能搜了,
  但普通聊天还是会去查 —— 这句话卡片上也明写着。
- **模式可以比这里更窄,但绝不会更宽** —— 每个 Custom Mode 在设置 → Modes →
  **它能做什么** 里有自己的八个开关,而且只能往下收。见下面的《模式》。
- **app 钥匙比模式还窄** —— 别的 app 拿着的每一把钥匙,在 Library → Token →
  **它能做什么** 里有自己的八个勾,而且一开始一个都没勾。「取文件」在那里永远勾不上。
  见上面的《Method 与 Routine》。
- **装好时哪些是开的** —— 凡是 Vaenyx 在这台电脑上本来就会做的,都是开的:听、念、看、
  画、读文档。**「上网」也是开的**:查不了资料的模型,会拿去年记住的东西回答今天的问题,
  而且答错时一样自信 —— 自信地答错比让它上网更糟。**默认关着的只有「取文件」**,
  它一直关到你自己决定为止 —— 那是 Vaenyx 去打开你自己的文件夹。
- **有两项会先自己说清楚再用** —— 各说一次,而且窗口里两个按钮都是真的:
  「把它关掉」就真的关掉。
  - **上网** —— 离开这台机器的,是你的模型拿去搜的那几个词。它们经由该模型自己的
    后台发出去,最终由另一端的一家搜索公司收到;这家公司不是 Vaenyx 选的,
    Vaenyx 自己也不会去联系它。这几个词是模型自己写的,所以里面可能出现你并没有
    打出来的内容。因为「上网」出厂就是开的,这段话在你第一次打开这张卡片时就会出现,
    而不是等一个你也许永远不会碰的开关。
  - **取文件** —— 大家漏掉的不是「Vaenyx 能读我的文件」,而是
    **文件里的字会交给正在回答的那个模型**,和你自己在聊天里打进去的内容一模一样;
    如果那是云端模型,它们就离开了这台机器。开文件的是 Vaenyx,从来不是模型;
    在你点名文件夹之前它一个字也读不到;而且任何 app 钥匙都永远拿不到这一项。
- **问一次到底花多少钱** —— 就写在卡片上,开关的上面。Vaenyx 自己不收费,以后也不会收;
  花出去的是你自己的模型连接。**你已经在付的订阅**(ChatGPT 走 Codex CLI、Claude)
  每次调用不额外花钱 —— 你用的是已经买下的额度,用完就是用完,不会另外收你钱。
  **按量计费的 API key**(OpenAI、Anthropic、Gemini、Groq 等等)按次计费,按走过去的
  量算;其中**看图和读文档最贵**,因为图比文字贵,而文档也是当成图来读的。
  **完全不花钱**的是本机语音和任何本地模型,因为它们就在这里跑。打开文件本身也不花钱 ——
  但文件里的字接着会交给回答你的那个模型,所以文件免费、答案该花多少还是多少。
  这里不写价格:价格是服务商的,会变,我们写下一个过期数字比不写更糟。
- **七行长得一模一样** —— 图、名字、由哪个模型做、**Test**、展开自己设置的箭头、开关。
- **试一行** —— 每一行都有 **Test** 按钮:真的把那件事做一次,拿一个答案已知的东西去试,
  然后告诉你三种结果之一 —— 成了、按失败那一方自己的说法失败了、或者这条路还没做出来。
  「听」和「念」是**这台设备**测的,不是服务器测的 —— 服务器既没有耳朵也没有嘴:
  「听」会录你三秒,把听到的字显示出来;「念」会真的念一句。
  按钮上停一下会显示按一次实际花什么代价,因为有几项是真花钱的。
- **连着但做不了这件事的模型会灰掉,不会消失** —— 你要能看见「它在,只是这里用不了」。
- **主模型只选一次** —— 在 Capabilities 最上面它自己那一行(或在 Models 卡片上按
  **Set As Default**)。跟随它的那几行会自动改成你选的那个名字。
- **某个引擎坏了怎么办** —— Vaenyx **不会**偷偷换成别的模型。它会告诉你是哪条路、
  为什么坏,你到这里改。这是故意的:偷偷换掉,你就永远不知道答案是谁写的。
- **如果你用的后台做不了你要的那件事** —— 只有一句话,而且到处都是同一句:
  _用某某后台,Vaenyx 不能做某某事_。它会**点名是哪个后台**、点名**做不了什么**,
  而且**只要有别的东西顶上来做了,就把顶上的那个也点出来,连同你为此付出的代价**。
  这里面有两种天天都会遇到:打不开 PDF 的模型,拿到的是这台机器从文件里抠出来的文字,
  所以图、表格和排版根本到不了它那里;看不了照片的模型,拿到的是另一个模型对照片的描述。
  两种都有用,但两种都不是原件 —— 所以也都不许冒充原件。
- **加模型只有一个地方** —— 下面的 Models 卡片,别处都不行。key 属于模型,不属于
  某一件事:一个服务商连一次,凡是它做得了的活,每一行都能挑它。Capabilities
  那边只负责挑。
- **Cloudflare Workers AI(免费画图)** —— 在 Models 卡片的 **Add a Model** 里选
  **Workers AI (Cloudflare)**。它要两样东西,因为用 Cloudflare 的 Workers AI 模板
  做出来的令牌说不出自己属于哪个账户:**令牌**(Cloudflare 控制台 → My Profile →
  API Tokens → Create Token → Workers AI 模板),以及**账户 ID** —— 登录后地址栏里
  就有,`dash.cloudflare.com/<那串长码>`。存之前 Vaenyx 会真的调一次去验,填错了
  你还看着这个输入框就会知道。同一个连接也能拿来聊天。连上它**不会**改变「画」那一行
  用的是谁:那一行你选了什么就还是什么,只有空着的行才会自己填上。连上之后,两个字段
  可以单独重存 —— 改一个填错的账户 ID,不用再去把令牌取一遍。
- **本机语音(免费、离线)** —— 在 **Models** 卡片最下面,按 **下载本机语音**。
  约 150 MB,只下这一次,下完这台电脑上就有了一个神经网络语音:不用 key、没有每次的
  费用、断网也能念。中文和英文音色都在里面。进度条就在那里;下好了,「念」那一行会
  自己用上它。要删也在同一块,删之前会先问你一次。至于**用哪个音色念**,是在
  「念」那一行选的 —— 那是这件事怎么做,不是装了什么。里面自带的两个之外还有别的音色,
  **选一个你还没下过的,会另外下大约 60 MB**:选项上会写明,进度就显示在你按下它的
  「念」那一行。

- **每家服务商拿你的内容做什么** —— 每张模型卡片和引擎列表旁边,都写着该服务商
  **自己条款里的原话**:训不训练、留存多久、带日期的出处链接。我们只照抄,不替你
  判断 —— 决定权在你。最要紧的一条:最顺手的两个免费选项(Gemini 免费档、Mistral
  免费档)**都默认拿你发的内容去训练**。

- **搜索 → 测试 → 使用** —— Models 里每张已连接的卡片就是一句话加一排按钮,第一个是**找型号**。它会现场问
  这个账号你的登录或 key 现在能用哪些型号(不是存好的清单),列出来。**测一次**会用这个
  型号真发一句话,显示引擎报的实际型号、用时和时间;答上来的才会出现**使用**按钮,
  使用中的型号才会出现在 Capabilities 各行和聊天框下面的切换里 —— 某个账号一个都没在用时,
  那一行干脆不显示型号下拉;**取消使用**随时拿掉。
  Claude 每次回答都报型号;Codex 回显线程设定的型号,套餐里没有的直接拒绝;用 key 的
  厂商不报型号,测试就按你选的显示。Connection 卡片上的**主模型快速测试**仍然按屏幕上
  选定的主模型发一句话。

## 10. 订阅通道 —— 把你的订阅借给自己的其他 app

- **是什么** —— 设置 → AI Settings → **Subscription Door**。你其他的 app 通过这台
  电脑借用你的 ChatGPT 和 Claude 订阅。
- **为什么需要它** —— 那两个订阅只有能跑命令行的机器才用得了,网页和云端服务器都不行。
- **打开** —— 拨那个开关。默认是关的。
- **把地址给 app** —— 用上面那条(这个页面自己的地址),旁边有复制按钮。
- **谁进得来** —— 只有拿着你在这里发的**模型钥匙**、而且设备在你私网里的 app。
  不用再维护邮箱名单:钥匙就是身份。
- **它能做什么** —— 有效模型钥匙会自动拿到所选订阅引擎**真实测试通过**的全部
  安全能力:文字、结构化结果、图片/PDF 输入和带可核验来源的网页搜索。模型钥匙不再有
  逐项开关。语音、生成图片、Shell、本机文件、浏览器登录、设置和账号操作永远不从
  这扇门出去。
- **测试全部能力** —— 真的调用两个 Subscription,逐项列出当前结果。没做完或测试失败
  的能力会灰显并写原因,不会冒充成 Provider 故障。网页搜索只有在 CLI 返回结构化、
  可核验 URL 时才显示可用。图片测试会真的发一张 256 像素的颜色图;PDF 测试会把
  一段每次都不同的代码印进文件,只有所选引擎确实读出代码才算通过。
- **app 可以按次选型号** —— app 能向这扇门要你登录能用的型号清单、先测某个
  型号再把工作分给它、每次调用点名用哪个。它的选择不会改你自己的主模型,一个
  app 的选择也不会改到另一个 app。
- **Token 不是模型钥匙** —— 这扇门只认模型钥匙。拿 Library → Token 里的 Method/
  Routine Token 来敲门,会得到它自己的回答(`RELAY_KEY_WRONG_KIND`),所以你永远
  分得清 app 手里是哪一种。两样东西绝不混:Token 在 Tokens 那个页面,模型钥匙在
  这里。
- **文件** —— app 发的是一条短命下载链接,不是文件本身。Vaenyx 只从你列出的域名取,
  用完立刻删除。Claude 会直接读 PDF;OpenAI 这条路由 Vaenyx 在本机把最多 20 页
  PDF 临时转成图片后交给 Codex,不使用 API key、付费 API 或外部转换服务。
- **会记下什么** —— 时间、任务类型、用了哪个订阅、耗时、成败。
  **切记:绝不记提示词、不记文件、不记答案。**
- **这个月** —— 同一张卡片上能看到这个月**谁花了多少**:每个 app、Vaenyx 自己,
  以及(作为历史)已作废的共享钥匙花过的部分,显示为「门钥匙」,按订阅分开。
  次数一定是真的;token 数只有引擎真报了才显示,绝不估算。
- **一个 app 一把模型钥匙、一个账号** —— 按 **添加 App**,起个名字,把钥匙交给它
  钥匙会留在这个 app 那一行 —— 平时用 •••• 遮住,旁边有「显示」和「复制」。
  然后 app 要**在它自己里面**用它自己的 ChatGPT 或 Claude 订阅登录,
  **登录之后才可用**:没连上的引擎会得到明确的「没连上」,绝不会误用你的账号。
  每个 app 的行上有真实能力状态、换钥匙和吊销。
- **只按一次「连接」** —— 每个 app 的行上有一个**「连接」**按钮,把 Owner 这边
  当前已有的 Subscription 登录分别复制进 app 档案。OpenAI 和 Claude 仍完全独立,
  所以一个可以可用、另一个仍未登录。复制出来的是独立一份 —— 吊销或断开那个 app,
  动不到你自己的登录。每次授予都会
  写进审计日志;你自己这边还没登录某个引擎时,按钮会灰显并写明原因。
- **旧的共享钥匙已作废。**每个 app 用自己的模型钥匙;旧的共享钥匙来敲门直接被拒。
- **前提** —— 那台设备必须在你的私网里,而且现在**门自己会查**:从公网来的请求会被
  明确拒绝(RELAY_TAILNET_REQUIRED),**钥匙对了也一样**。钥匙泄漏了,别人在公网上
  也烧不到你的订阅。Vaenyx 网页本身不受影响 —— 手机浏览器不装 Tailscale 照样打得开。

## 11. 不在电脑旁怎么用

- **引导式设置** —— 设置 → **手机访问**(装完第一次运行的最后一步也有同样的入口)。
  三盏灯 —— _Tailscale 已安装_、_已登录_、_手机通道已开_ —— 每盏灯旁边都有一个
  一键修复按钮:Vaenyx 会替你安装免费的 Tailscale 客户端、打开它的登录页、开启
  通道。三盏灯都绿了,就出现一个二维码。
- **二维码等公网确认才出来** —— 出码之前,Vaenyx 会自己去问公网 DNS:这个地址
  在外面到底存不存在。还没生效时,页面会明说,并自动反复重查。如果 Tailscale
  要求先做一次性的批准(一个叫 Funnel 的全网设置),这里会出现一个
  **去 Tailscale 批准** 按钮 —— 在打开的页面点一下,一辈子一次,重查自动变绿。
- **扫码** —— 用手机相机扫,打开出现的链接。二维码由 Vaenyx 在你自己的机器上
  画出来;这个地址从不发给任何外部二维码或短链服务。
- **地址是公开的,你的 Vaenyx 不是** —— 通道给这台机器一个任何人都能输入的
  https 地址,但地址后面的一切都要先输你的 Vaenyx 密码。手机上不用装 Tailscale。
- **在手机上登录** —— 用你自己的 Vaenyx 账号,和在电脑上一样。
- **加到主屏幕** —— iPhone:Safari → 分享 → 「添加到主屏幕」;Android:Chrome →
  右上角菜单 → 「安装应用」(或「添加到主屏幕」)。之后用起来就像一个 app。
- **手机打不开怎么办** —— 刚开启的通道要过一两分钟才能从外网访问。「手机访问」
  页会自动重查,确认地址真的在公网上了才出二维码;如果那一刻问不到公网 DNS,
  就等一分钟再扫一次 —— 那时能证明的只有手机。
- **一直好好的设备突然打不开** —— 那台设备上的等待页会自己诊断。当它说「某家
  公共 DNS 在答错」时,页面会先给一个「让它清掉缓存」的一键按钮(Cloudflare
  有公开清缓存接口;Google 的等价工具是个链接)—— 值得点一下,但**不一定
  管用**。**可靠的修法**是按钮下面那几步:把这台设备指到页面点名的健康那家
  DNS,修好后等待页会自己刷新。Vaenyx 自己也在盯着这个地址,哪家答错了会
  推送预警给你。
- **通知** —— 设置 → Notifications → 允许,然后点 **Test** 确认真能收到。
- **几条结果合成一条** —— 上一条还挂着、新的又来了,就会合并成一条 _Vaenyx (n)_,
  一行一个;展开就能看明细,点一下打开 Vaenyx。划掉之后,下一条又是完整的单条通知。
- **正开着 Vaenyx 的设备不弹通知** —— 结果就在你眼前,不需要横幅再来一遍;
  关着或在后台的设备照常收到。
- **控制台路线** —— Vaenyx 文件夹里的 `Vaenyx-Connect-Tailscale.cmd` 可以手动跑
  同样的 Tailscale 命令,用的是装在 Program Files 下的客户端。

## 12. 备份与恢复

- **马上备份一次** —— 设置 → Backup → **Create backup**。
- **自动备份** —— 同一个页面:关闭、每天、每周,以及在几点。
- **加密** —— 设一个备份密码。**警告**:密码丢了,这份备份**谁也打不开,包括你自己**。
- **存在哪** —— 那个页面上的目标位置;保留几份看 _Keep_ 设置。
- **恢复** —— 设置 → Backup → 选一份 → **Restore**。
  **警告:恢复会覆盖你现在所有的数据,不可撤销。**
- **注意** —— push 到 GitHub 不算备份,deploy 也不算备份。

## 13. 模式(Modes)

- **模式是什么** —— 一种受限的进入方式,给共用或借出的设备用。
- **新建** —— 设置 → Modes → **New mode**,给它一个 PIN。
- **它锁住什么** —— 设置、这个模式以外的对话,以及(如果你要的话)在这个模式里
  Vaenyx 到底准不准做某件事。
- **这个模式能做什么** —— 在这个模式的卡片上,点**它能做什么**。和 AI 设置里一模一样的
  八项能力,同样的顺序,每项一个开关。把借出去的设备不该做的事关掉:比如一个不准画图、
  不准看照片、永远碰不到你文件的模式。
  - **「上网」这一项要留神。** 它和 AI 设置里的缺口一模一样:在模式里关掉「上网」,
    Method 和 app 钥匙确实搜不了,但这个模式里的普通聊天还是会去查。别以为把设备交出去
    时这个开关切断了它的网 —— 同一个模式设置里的「Local model only」才切得断。
  - **模式只能往窄里收。** 整台机器已经关掉的东西,模式里给不了。那几行显示的是
    **整台机器都关着**,而不是一个开关 —— 那里放开关等于放一个按了没用的开关。
  - **收窄之后就一直窄。** 你之后把某项能力在整台机器上重新打开,并**不会**顺手还给
    已经收窄过的模式:那一行会重新变成开关,但仍然是关的,开不开由你决定。
  - **只能在 User Mode 里改。** 在模式里面,这张表既改不了也看不了 —— 不管有没有勾
    「Lock settings」。这正是重点:一个从里面撬不开的模式。
  - **在里面是什么感觉** —— 那件事就是不会发生,Vaenyx 会说当前模式不允许。它绝不会
    叫拿着设备的人去改设置,因为那个人根本改不了。
- **设备的模式由设备自己定** —— 在设备上进了某个模式,它以后就一直从那个模式
  打开;退出(有退出 PIN 就输 PIN),就回到 User Mode 打开。设置 → Modes →
  Devices **只显示情况**:每台设备现在在哪个模式、最后使用时间,以及浏览器
  报得出来的**硬件型号**——那里没有要选的东西。几台设备名字一样分不清时,
  拿起那台打开 Vaenyx,它会跳到列表最上面、显示「刚刚在用」——认出来先给它
  起个自己的名字。起过名字的设备,在它自己屏幕的 logo 下面也会显示名字,
  拿在手里就认得出。
- **模式的 PIN 忘了?**在 User Mode 里编辑那个模式的卡片,直接设一个新的
  进入/退出 PIN(或勾 Remove 清掉)。只有 User Mode 能改 —— 忘了 PIN 永远
  锁不住你自己的机器。
- **通知不出模式。**每台设备只收到属于它所在模式的推送:模式里的回复、任务结果
  只响那个模式的设备,你自己的设备不会响 —— 反过来也一样。没绑定模式的设备算
  你自己的(User Mode)。
- **模式向你的主对话汇报。**模式卡片上设的定期汇报(每日 / 每周 / 每月)会作为
  一条消息出现在「Vaenyx 开口说话的那个对话」里 —— 多少条消息、几个对话、规则
  拒答了几次 —— 推送只提醒你去看。规则每拒答一个问题,主对话也会立刻收到一条,
  带问题和时间。任何 Vaenyx 要告诉你的事,都从这同一个对话来。
- **退出模式** —— 屏幕顶部那个徽章。
- **你以前建的模式** —— 在这个功能出现之前建的模式,自己不加任何限制,直到你打开
  **它能做什么**并关掉点什么为止。你原来的东西没有被动过。

## 15. 隐私与法律

- **法律文件** —— 设置 → Legal,就是随 app 发布的那几份正式文本。
- **什么会离开这台电脑** —— 你发给模型后端的内容。Vaenyx 不会声称「什么都不出去」,
  因为用哪个后端是你自己选的。
- **你自己的文件** —— 一个都不出去,除非你把「取文件」打开并亲手点名了文件夹;
  那之后,那几个文件夹里的文件会像你手动附上去的东西一样发给模型。
  见上面《你电脑上的文件》。
- **审计记录** —— Guard 页面列出放行和拒绝了什么。
- **改密码** —— 设置 → Personal。
- **登出所有设备** —— 设置 → Personal → **Log out everywhere**。

## 出问题怎么办

Vaenyx 现在会把技术故障挡在一层面向使用者的安全边界后面。你看到的消息会说明
什么失败了、已有数据是否安全,并给出下一步 —— 重试、重新连接模型、打开设置,
或查看本地日志。每条这类消息都有稳定错误码和诊断编号。如果问题反复出现,
记下这两个值;对应的限长、已隐去敏感信息的详情只保存在这台电脑的
`userdata/logs/owner-errors.log`。原始命令输出、本地路径、access token、终端控制码
和 stack trace 都不会显示在 app 里,也不会从 API 发出去。不用 PowerShell 修复;
先按消息给出的按钮或路径操作。

| 你看到的现象                                 | 一句话解决                                                                                               |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| 整个打不开                                   | 电脑关机或睡着了,把它叫醒。                                                                              |
| 电脑能开,手机不行                            | 刚开的通道要等一分钟 —— 稍等再试。还不行:设置 → 手机访问,看三盏灯。                                      |
| 某台电脑打不开,手机用流量却能开              | 几乎一定是那台电脑的 DNS。见下面《不是 Vaenyx 的锅,是网络的时候》。                                      |
| 一直停在「正在启动…这个页面会自己打开」      | 这句话只在头十秒是真的。超过六秒页面就会把它换成真正的原因 —— 去读那段。                                 |
| 浏览器控制台报 `ERR_NAME_NOT_RESOLVED`       | 这台设备查不到这个地址。是 DNS,不是 Vaenyx。把这台设备的 DNS 改成 `8.8.8.8` —— 见下。                    |
| 某个订阅显示「Not signed in」                | 设置 → AI Settings → 重新登录那一个。                                                                    |
| 引擎失败了,然后就没下文了                    | 这是故意的。看清是哪条路坏了,在那一行换一个引擎。                                                        |
| 错误里有 `VX-…` 和诊断编号                   | 按消息给出的动作操作。再次发生时记下这两个值;隐去敏感信息的本地详情在 `userdata/logs/owner-errors.log`。 |
| 语音按钮没反应                               | 「听」这一行没设引擎,或者被关掉了。设置 → AI Settings → Capabilities → 听。                              |
| 回复上没有 ▶ 按钮                            | 「念」被关掉了。设置 → AI Settings → Capabilities → 念。                                                 |
| 提示「你把这一项关掉了」                     | 那确实是你关的。到设置 → AI Settings → Capabilities,把那一行打开。                                       |
| 提示「你当前所在的模式不允许」               | 那个模式被收窄了,而且在里面撬不开。先退出模式(顶部那个标记),再到设置 → Modes → 那个模式 → 它能做什么。   |
| 提示「这把 app key 没有拿到这一项」          | 那个 app 是拿自己的 Token 来的。到 Library → Token → 那把钥匙 → 它能做什么,勾上它。                      |
| 提示「任何 app key 都拿不到这一项」          | 那是「取文件」,任何钥匙都拿不到 —— 这不是设置,是规矩。改从聊天里做这件事。                               |
| 照片回来没有标注                             | 「看」这一行没设引擎或被关掉了,或者模型没找到可标的东西。                                                |
| PDF 先问我页数                               | 超过十页就会问,故意的 —— 花钱之前先告诉你要花多少。                                                      |
| 我的 app 拿到的是免费模型                    | 门关着,或那台设备不在私网,或那个 app 还没登录它自己的订阅。                                              |
| Relay 能力显示灰色                           | 按「测试全部能力」,看该引擎写的是未登录、未测试、Probe 失败,还是尚未实现。                               |
| 半夜的定时任务失败了                         | 电脑睡了。失败原因会留在那次运行上。                                                                     |
| 更新提示条不消失                             | 点它,然后重启。                                                                                          |

## 不是 Vaenyx 的锅,是网络的时候

Vaenyx 已经被冤枉过两次。两次 app、通道、模型全都是好的,两次大家能看到的
都只有同一个页面 ——「正在启动…」。下面是一分钟之内分清楚它们的办法,以及
那两次分别是什么。

**先确定问题在哪一边。** 在跑 Vaenyx 的那台电脑上开 `http://127.0.0.1:3000`。
能开,就说明 **Vaenyx 是好的**,问题出在另一台设备到这台电脑之间 —— 下面讲的
全是这一段路,app 本身没毛病。

- **互联网的通讯录一度说这个地址不存在**(2026 年 8 月 17 日)。
  你的 Vaenyx 地址存在一本公共通讯录里。有几个小时,那些大型公共查询服务手里
  记着一条「查无此地址」的旧答案,而**总部的正本从头到尾都是对的**。大约三次
  查询坏一次;而浏览器一旦听到「查无此地址」,会记住好几分钟 —— 所以感觉不像
  时好时坏,而像彻底死了。
  - **判断依据:** 浏览器报 `ERR_NAME_NOT_RESOLVED` 或 `DNS_PROBE_FINISHED_NXDOMAIN`,
    而跑 Vaenyx 的那台电脑明显是好好的。
  - **解法:不用修,也修不了。** 你这边没有任何东西坏掉,你怎么改也不会更快 ——
    那些记岔了的答案会自己过期,通常几个小时。重新发布地址试过了,没用。
  - **这期间:** 在跑 Vaenyx 的那台电脑上直接用 `http://127.0.0.1:3000`,
    它根本不经过通讯录。
  - **以后怎么再证一次:** 拿三个名字各查十来次 —— 一个你确定好的名字、一个你
    编的假名字、还有出问题的这个地址。好名字 0/12 失败、假名字 12/12 失败、
    你的地址 5/12 失败,就是这个病的特征,而且一次就能把路由器、你的网络和
    app 全部排除掉。

- **Tailscale 升级做了一半**(2026 年 8 月 4 日)。Vaenyx 自己那个安装按钮,
  在一个本来好好的 Tailscale 上又跑了一遍安装程序,还告诉 Windows 不用重启。
  于是 Windows 一直等着换那个网卡驱动文件,Tailscale 的后台服务永远起不来,
  远程地址也就不通了。**重启服务是没用的。**
  - **判断依据:** 地址是在某次安装或更新 Tailscale 之后立刻不通的,而且这台
    电脑此后一次都没重启过。
  - **解法:** 重启 Windows。重启后如果还打不开,再双击
    `Vaenyx-Repair-Phone-Access.cmd` —— 它现在第一件事就是检查这个,不会再空等。
  - 这次的起因是我们自己的代码,已经修好;这条留着,是因为任何一次中断的
    Tailscale 更新都会长成同一个样子。

**现在那个等待页会怎么表现。** 头六秒它说 Vaenyx 正在启动,因为重启确实要十秒
左右。超过六秒,它就把那句话换成真正的原因,按可能性排好,包括 DNS 这一条和
要填的地址。它还会跨页面记住 —— 所以一台永远连不上的设备,一打开就直接看到
实话,而不是每次都重新数六秒。
