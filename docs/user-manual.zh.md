# Vaenyx 使用手册

Vaenyx 能做的每一件事,按你会用到的顺序排。一条一件事:是什么、在哪点、点完会怎样。

在 app 里看这份手册:**设置 → Manual**。

---

## 先知道三件事

- Vaenyx 跑在**你自己那台电脑**上。那台电脑关机或睡着,什么都用不了 —— 手机不行、
  浏览器不行、定时任务也不会跑。
- 你的数据都在那台电脑上,放在 `userdata/` 里。Vaenyx 自己不会把它传到任何地方。
- 回答你的那个模型**不在**你电脑上(除非你选了本地模型)。你打的字会发给你连接的那个
  模型后端。

---

## 1. 开机与关机

- **启动** —— 双击 Vaenyx 文件夹里的 `Vaenyx-Start.cmd`。电脑开机时它也会自己启动。
- **打开** —— 在那台电脑上用浏览器开 `http://127.0.0.1:3000`;手机用远程地址(见
  《不在电脑旁怎么用》)。
- **停止** —— 设置 → System → **Stop Vaenyx**。或者关掉启动器打开的那个窗口。
- **重启** —— 设置 → System → **Restart**。约十秒,页面会自己接回来。
- **登录** —— 你的 Owner 名字和密码,第一次运行时设的。
- **忘记密码** —— 没有找回。只能从备份恢复,或者重开一个新实例。
  **警告**:这是唯一一件谁也帮不了你的事。

## 2. 更新

- **检查更新** —— 设置 → System → **Check for updates**。
- **安装** —— 点 **Download**,再点 **Restart**。版本号在左下角,点它看这次改了什么。
- **底部会弹出提示条**,说明有新版本。你正在打字时它绝不会自己刷新。

## 3. 聊天

- **随便问** —— 在最下面的框里打字,按 **Send**。
- **用说的** —— 麦克风按钮。需要「听」这一行开着并且设好引擎
  (设置 → AI Settings → Capabilities)。
- **听回答** —— 每条回复右下角的 ▶ 按钮。它念的是**总结**,不会把标点念出来。
  只有你是用说的,它才会主动用说的回你。如果你把「念」这一行关掉了
  (AI Settings → Capabilities),这个按钮直接不出现;你自己录的语音消息照样能回放,
  因为那是你的声音,不是 Vaenyx 在说话。
- **发照片** —— 相机按钮(现拍)或图片按钮(选一张)。模型自己看照片,你不用描述它。
- **在照片上标东西** —— 用你自己的话让它标出来就行。照片上会出现红点和名字。
  照片上的图层按钮可以开关这些标注。
- **看清楚一点** —— 点照片全屏,两指放大。标注和图层按钮会跟着一起放大。
- **发文件** —— 文件按钮。目前只支持 PDF。
  - 超过十页会**先问你**,并告诉你有多少页 —— 长文档在付费模型上是真金白银。
  - 如果「读文档」这一行是关的(AI Settings → Capabilities),文件在门口就被挡下,
    Vaenyx 会告诉你是哪个开关挡的。
- **打断回答** —— 回答过程中按 **Stop**,立刻停。
- **换模型 / 换思考强度** —— 输入框下面那两个选择器。只影响当前这个对话。
- **改名、归档、删除对话** —— 对话顶部的 ⋮ 菜单。
- **未读** —— 对话左边那颗彩色圆点会呼吸,表示里面有新东西。
- **它记得多少** —— 最近三十条完整记得,更早的压成一份滚动摘要,再加上你批准过的
  《Vaenyx Me》条目。
- **查资料** —— 答案取决于最新情况时,它可以联网搜索并打开网页;查不到就会明说
  「我核不到」,而不是凭记忆编。
- **你电脑上的文件** —— 除非你把「取文件」这一行打开,**并且**亲手点名它可以看哪几个
  文件夹(AI Settings → Capabilities → 取文件),否则 Vaenyx 读不到这台电脑上的任何
  东西。两件事缺一不可:只开开关、一个文件夹都没点名,它照样一个字都读不到。点名之后,
  也只有那几个文件夹里的东西打得开,而且只限文字文件 —— 这台机器上的其他东西不会交给
  任何模型。出厂时这一行是关的,名单是空的。

## 4. 项目

- **项目是什么** —— 一组相关对话的文件夹,可以有自己的常驻指令。
- **新建** —— Projects → **New project**。
- **常驻指令** —— Projects → 选一个 → **Instructions**。这个项目里的每个对话都会带上它。
- **把对话放进项目** —— 对话里的 ⋮ 菜单 → **Move to project**。

## 5. Vaenyx Me

- **是什么** —— Vaenyx 注意到的、关于你的事实,之后每个对话都会用上。
- **在哪** —— **Vaenyx Me** 页面。
- **没批准的一律不用。** 每条候选都有 Approve / Reject。
- **以后想删** —— 同一个页面,删掉即可。
- **自己加一条** —— 那个页面上的手动表单。

## 6. Method 与 Routine

- **Method** —— Vaenyx 会做的一件小事,用大白话的步骤写成。
- **Routine** —— 你真正在用的成品,由一个或多个 Method 组成。它看起来像一个对话,
  用着用着会长出额外的按钮(Journal、Gallery)。
- **怎么做一个** —— 在对话里把步骤说出来。一步就是一个 Method,多步就是一个 Routine。
  Vaenyx 会起草,并在保存前给你试跑一次。
- **放在哪** —— **Library** 页面。
- **改配方** —— Library → 那个 Method → **Edit recipe**。
- **试跑** —— 同一个页面。是真跑,但不改任何东西。
- **标签** —— 在 Library 页面改名和归类。
- **导入 / 导出** —— Library → **Import Skill** 可以吃一个 SKILL.md 文件夹;
  每个 Method 也能同样导出。

## 7. 社区

- **看别人做的** —— **Community** 页面。
- **安装** —— 每个条目上的 Install 按钮,装完进你的 Library。
- **发布自己的** —— 你自己条目上的 Publish 按钮。需要 Google 或 GitHub 登录,
  因为上面要署你的名。
- **暂停发布** —— 设置 → Sharing。暂停期间你的东西一律不出去。
- **你做的纠正可以变成共享示例** —— 一定先去掉个人信息,而且事后可以撤回
  (设置 → Sharing → 飞轮列表)。

## 8. 任务与定时

- **一次性任务** —— 让它做一件事,Vaenyx 会归档成一个任务。
- **定时任务** —— **Scheduled** 页面。可设每天、每周或按模式运行。
- **看跑过什么** —— 同一个页面:每次运行、结果、用了多久。
- **取消或重试** —— 运行记录上的按钮。
- **跟任务对话** —— 任务底部那个输入框,和聊天那个一样能发**照片、PDF、语音**。
  它底下本来就是同一个对话,所以**每一个任务都自动有**,不管是多久以前建的。
- **前提** —— 到点时电脑必须醒着。如果睡着了,那次运行会标为失败并写明原因;
  绝不会悄悄换个模型重跑。

## 9. AI 设置 —— 能力与模型

- **在哪** —— 设置 → **AI Settings** → **Capabilities** 那张卡。跟模型有关的一切现在
  都在这一张卡上:准不准做、由哪个模型做、测一次看它真的行不行。
- **免费额度** —— 标题旁边的 **免费额度** 按钮打开上一次查到的答案;挨着它的
  **再问一次** 会重新问一遍主模型,问完直接把新答案给你看。
  **注意**:结果旁边会写明**是哪个模型答的、哪天答的** —— 免费额度天天变,而模型会非常
  自信地答错。用之前请到服务商官网确认。
- **分成两段,绝不混**
  - *用你已有的订阅* —— ChatGPT(Codex CLI)和 Claude。在 app 里点一次登录即可。
    这**不是**免费额度,是你自己花钱买的订阅。
  - *免费 API 额度* —— 选一家,粘贴它的 key。
- **Capabilities 那张表就是全部** —— 一种能力一行,一行里两件事都在:这件事由**哪个模型**
  做,以及**准不准**做。听、念、看、画各自选模型;读文档、取文件和上网跟主模型走,
  行上会写明。
  - **听** *(声音进)* —— 语音转文字。
  - **念** *(声音出)* —— 文字转语音。
  - **看** *(图形进)* —— 看照片。
  - **画** *(图形出)* —— 生成图片。
  - **读文档** *(多页文档、PDF)* —— 你传上来的文件。
  - **取文件** *(本机文件)* —— 打开你亲手点名的那几个文件夹里的文字文件,名单就在这一行
    自己的设置里。只限文字文件,而且不能太大。目前只有 Claude 订阅那个后端真的会打开
    文件;换成别的主模型,Vaenyx 会直说做不到,而不是瞎猜。PDF 仍然走聊天里的文件按钮,
    那是「读文档」。Method 和 Routine 目前还用不了这一项。
  - **上网** *(网页)* —— 出去查网页。
- **开关就是天花板** —— 在某一行关掉的东西,任何 Method、任何模式、任何 app 钥匙都够不着,
  不管它们要什么。只有「上网」还差一步:关掉它,Method 和 app 钥匙就不能搜了,
  但普通聊天还是会去查 —— 这句话卡片上也明写着。
- **装好时哪些是开的** —— 凡是 Vaenyx 在这台电脑上本来就会做的,都是开的:听、念、看、
  画、读文档。会伸到机器外面去的那两项默认关着,直到你自己决定:**上网**和**取文件**。
- **七行长得一模一样** —— 图、名字、由哪个模型做、**Test**、展开自己设置的箭头、开关。
- **试一行** —— 每一行都有 **Test** 按钮:真的把那件事做一次,拿一个答案已知的东西去试,
  然后告诉你三种结果之一 —— 成了、按失败那一方自己的说法失败了、或者这条路还没做出来。
  「听」和「念」是**这台设备**测的,不是服务器测的 —— 服务器既没有耳朵也没有嘴:
  「听」会录你三秒,把听到的字显示出来;「念」会真的念一句。
  按钮上停一下会显示按一次实际花什么代价,因为有几项是真花钱的。
- **连着但做不了这件事的模型会灰掉,不会消失** —— 你要能看见「它在,只是这里用不了」。
- **主模型只在一个地方选** —— 下面 Models 那张卡片,按 **Set As Default**。
  跟着主模型走的那几行会自动改成你选的那个名字。
- **某个引擎坏了怎么办** —— Vaenyx **不会**偷偷换成别的模型。它会告诉你是哪条路、
  为什么坏,你到这里改。这是故意的:偷偷换掉,你就永远不知道答案是谁写的。
- **加模型只有一个地方** —— 下面的 Models 卡片。key 属于模型,不属于某一件事:
  一个服务商连一次,凡是它做得了的活,每一行都能挑它。Capabilities 那边只负责挑。

## 10. 订阅通道 —— 把你的订阅借给自己的其他 app

- **是什么** —— 设置 → AI Settings → **Subscription Door**。你其他的 app 通过这台
  电脑借用你的 ChatGPT 和 Claude 订阅。
- **为什么需要它** —— 那两个订阅只有能跑命令行的机器才用得了,网页和云端服务器都不行。
- **打开** —— 拨那个开关。默认是关的。
- **把地址给 app** —— 用上面那条(这个页面自己的地址),旁边有复制按钮。
- **谁进得来** —— 只有你列出的邮箱。其他人一律被拒,他们的 app 自动改用免费模型。
- **它能做什么** —— 文字,以及读图/读 PDF。**不能**做语音、不能生成图片,
  界面上会灰着写清楚。
- **文件** —— app 发的是一条短命下载链接,不是文件本身。Vaenyx 只从你列出的域名取,
  用完立刻删除。
- **会记下什么** —— 时间、任务类型、用了哪个订阅、耗时、成败。
  **切记:绝不记提示词、不记文件、不记答案。**
- **测试** —— 每个订阅一个 Test 按钮,**真发一次调用**。绿勾就是真的通了。
- **前提** —— 那台设备必须在你的私网里。不在的话,它连这扇门都找不到,会自己降级。

## 11. 不在电脑旁怎么用

- **地址** —— 你那台机器的私网地址,就是 Subscription Door 卡片里显示的那个。
- **要求** —— 手机必须在同一个私网里(Tailscale)。
- **加到主屏** —— 用浏览器的「添加到主屏幕」,之后用起来就像一个 app。
- **通知** —— 设置 → Notifications → 允许,然后点 **Test** 确认真能收到。

## 12. 备份与恢复

- **马上备份一次** —— 设置 → Backup → **Create backup**。
- **自动备份** —— 同一个页面:关闭、每天、每周,以及在几点。
- **加密** —— 设一个备份密码。**警告**:密码丢了,这份备份**谁也打不开,包括你自己**。
- **存在哪** —— 那个页面上的目标位置;保留几份看 *Keep* 设置。
- **恢复** —— 设置 → Backup → 选一份 → **Restore**。
  **警告:恢复会覆盖你现在所有的数据,不可撤销。**
- **注意** —— push 到 GitHub 不算备份,deploy 也不算备份。

## 13. 模式(Modes)

- **模式是什么** —— 一种受限的进入方式,给共用或借出的设备用。
- **新建** —— 设置 → Modes → **New mode**,给它一个 PIN。
- **它锁住什么** —— 设置,以及这个模式以外的对话。
- **绑定设备** —— 设置 → Modes → Devices,让某台设备每次都以那个模式打开。
- **退出模式** —— 屏幕顶部那个徽章。

## 14. 外观与语言

- **主题** —— 设置 → Personal。按设备保存。
- **聊天字号** —— 同一个页面。
- **语言** —— 设置 → Language,立刻切换。
- **助手的名字** —— 设置 → Personal。这台实例自己的名字在 AI Settings → Identity。

## 15. 隐私与法律

- **法律文件** —— 设置 → Legal,就是随 app 发布的那几份正式文本。
- **什么会离开这台电脑** —— 你发给模型后端的内容。Vaenyx 不会声称「什么都不出去」,
  因为用哪个后端是你自己选的。
- **你自己的文件** —— 一个都不出去,除非你把「取文件」打开并亲手点名了文件夹;
  那之后,那几个文件夹里的文件会像你手动附上去的东西一样发给模型。
  见上面《你电脑上的文件》。
- **审计记录** —— Guard 页面列出放行和拒绝了什么。
- **改密码** —— 设置 → Personal。
- **登出所有设备** —— 设置 → Personal → **Log out everywhere**。

## 出问题怎么办

| 你看到的现象 | 一句话解决 |
|---|---|
| 整个打不开 | 电脑关机或睡着了,把它叫醒。 |
| 电脑能开,手机不行 | 手机掉出私网了,重连 Tailscale。 |
| 某个订阅显示「Not signed in」 | 设置 → AI Settings → 重新登录那一个。 |
| 引擎失败了,然后就没下文了 | 这是故意的。看清是哪条路坏了,在那一行换一个引擎。 |
| 语音按钮没反应 | 「听」这一行没设引擎,或者被关掉了。设置 → AI Settings → Capabilities → 听。 |
| 回复上没有 ▶ 按钮 | 「念」被关掉了。设置 → AI Settings → Capabilities → 念。 |
| 提示「你把这一项关掉了」 | 那确实是你关的。到设置 → AI Settings → Capabilities,把那一行打开。 |
| 照片回来没有标注 | 「看」这一行没设引擎或被关掉了,或者模型没找到可标的东西。 |
| PDF 先问我页数 | 超过十页就会问,故意的 —— 花钱之前先告诉你要花多少。 |
| 我的 app 拿到的是免费模型 | 门关着,或那台设备不在私网,或那个邮箱不在 Owner 清单里。 |
| 半夜的定时任务失败了 | 电脑睡了。失败原因会留在那次运行上。 |
| 更新提示条不消失 | 点它,然后重启。 |
